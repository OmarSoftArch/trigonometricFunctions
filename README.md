# رحلة فهم الدوال المثلثية

مرحباً بك في هذا المشروع التعليمي التفاعلي الذي يهدف إلى شرح الدوال المثلثية من الأساس الحقيقي وحتى المستوى المتقدم، ليس بالحفظ، بل بالفهم العميق والمحاكاة التفاعلية.

## المتطلبات الأساسية
- متصفح ويب حديث (يفضل Chrome, Firefox, أو Edge).
- تثبيت Node.js على جهازك لتشغيل خادم التطوير.

## طريقة التشغيل

1. **تثبيت الحزم (الاعتماديات):**
   افتح موجه الأوامر (Terminal/Command Prompt) في مجلد المشروع، ثم قم بتشغيل الأمر التالي:
   ```bash
   npm install
   ```

2. **تشغيل المشروع:**
   بعد انتهاء التثبيت، قم بتشغيل خادم التطوير باستخدام الأمر:
   ```bash
   npm run dev
   ```

3. **فتح التطبيق:**
   ستظهر لك رسالة في موجه الأوامر تحتوي على الرابط المحلي (غالباً ما يكون `http://localhost:5173/`).
   افتح هذا الرابط في المتصفح لرؤية التطبيق التفاعلي.

## خطة التعلم المقترحة
ننصح باتباع الخطة التالية لفهم الدوال المثلثية بعمق:

### الأسبوع الأول: التأسيس الهندسي
- **اليوم 1:** الدرس 1 (الإحداثيات والمستوى) والدرس 2 (الطول والميل). ركز على فهم x, y, والميل وكيف نحسب المسافة.
- **اليوم 2:** الدرس 3 (معنى الزاوية كدوران) والدرس 4 (الدائرة الوحدة). افهم لماذا نستخدم دائرة نصف قطرها 1.
- **اليوم 3:** مراجعة وتطبيق مفاهيم الدائرة والمحاور مع تحريك المحاكاة وتجربة أرقام مختلفة.

### الأسبوع الثاني: الدوال الأساسية والعلاقات
- **اليوم 1:** الدرس 5 (العلاقة بين الدائرة والمثلث القائم) والدرس 6 (tan كميل).
- **اليوم 2:** الدرس 7 (مقلوبات الدوال sec, csc, cot) والدرس 8 (القيم الخاصة للزوايا).
- **اليوم 3:** الدرس 9 (الأرباع والإشارات). حاول استنتاج الإشارات بنفسك قبل قراءتها.

### الأسبوع الثالث: الراديان والموجات والمتقدم
- **اليوم 1:** الدرس 10 (الراديان) والدرس 11 (الرسوم البيانية للدوال).
- **اليوم 2:** الدرس 12 (المتطابقات المثلثية). لاحظ كيف تنبع جميعها من دائرة الوحدة ونظرية فيثاغورس.
- **اليوم 3:** الدرس 13 (التطبيقات الواقعية) والدرس 14 (المرحلة المتقدمة - الموجات).

## ملاحظة هامة
الهدف هو **الفهم** وليس الحفظ. حاول التفاعل مع المحاكاة في كل درس ورؤية التغيرات بعينك لتستوعب الفكرة الهندسية خلف كل مفهوم.

نتمنى لك رحلة تعلم ممتعة!
